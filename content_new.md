### Блок 1. Как работают LLM, инструменты и промпт-инжиниринг — 3 дня

*   **Тема 1. Эволюция от машинного кода к ИИ-разработке.** ИИ-программирование vs вайб-кодинг. Почему навык управления ИИ сегодня критически важен.
    *   *О чем:* Вводная лекция о смене парадигмы в IT, разнице между хаотичным использованием нейросетей («вайб-кодинг») и системным инженерным подходом.
    *   *Старый курс:* **Да**, раздел «Введение» → Темы 1, 2, 3.
*   **Тема 2. Устройство LLM на уровне практика.** Токены, контекстное окно, природа галлюцинаций, temperature и детерминизм. Почему модель «не знает» ваш код и данные по умолчанию.
    *   *О чем:* Технические ограничения моделей, математика токенов, почему нельзя загрузить огромный проект целиком и как настройки креативности влияют на результат.
    *   *Старый курс:* **Частично**, расширено темой 1 из Блока 1 нового курса.
*   **Тема 3. Базовые техники промптов и управление контекстом.** Роль, контекст, few-shot примеры (обучение на примерах), декомпозиция сложной задачи, итеративное уточнение.
    *   *О чем:* Правила составления запросов для получения предсказуемых ответов, управление контекстом ИИ-ассистента для точного удержания задачи.
    *   *Старый курс:* **Да**, объединены Тема 2 из Блока 1 нового курса и раздел «Практика» → Тема 3.
*   **Тема 4. Структурированный вывод.** Получение JSON/Markdown/SQL по схеме, валидация ответа, действия при невалидном или неполном результате.
    *   *О чем:* Как заставить ИИ отдавать ответы в строгом машиночитаемом формате для дальнейшей автоматизации и что делать, если ИИ нарушил структуру.
    *   *Старый курс:* **Нет**, новая тема из Блока 1 нового курса.
*   **Тема 5. Границы применения ИИ.** Детерминированные vs генеративные задачи, цена ошибки, где ИИ только мешает. Умение сказать «здесь ИИ не нужен».
    *   *О чем:* Критический анализ задач. Определение зон, где классический алгоритм эффективнее, дешевле и надежнее, чем нейросеть.
    *   *Старый курс:* **Нет**, новая тема из Блока 1 нового курса.

    *   *О чем:* Обзор актуального софта для работы с ИИ, различия между интерфейсами, особенности локальных и облачных решений.
    *   *Старый курс:* **Да**, полностью перенесено из раздела «Инструменты» → Темы 1, 2, 3.
*   **Тема 7. Первичная настройка и спецификации.** Почему первичная настройка Cursor — это основа нормальной работы. Как сгенерировать базовую спецификацию (`.cursorrules`), если проект туманный, а ТЗ не существует.
    *   *О чем:* Подготовка рабочего пространства, создание файлов инструкций для ИИ, правила инициализации проекта при дефиците вводных данных.
    *   *Старый курс:* **Да**, полностью перенесено из раздела «Практика» → Темы 1, 2.
*   **Тема 8. IDE-ассистенты и контекстная инженерия.** Автодополнение, чат, агентный режим; как собирать контекст (правила проекта, нужные файлы); принцип «ИИ пишет — человек проверяет». Контроль и дебаг работы ИИ.
    *   *О чем:* Практическая работа с кодом и документами в реальном времени, управление файловым контекстом, методы отслеживания и исправления ошибок за ИИ.
    *   *Старый курс:* **Да**, объединены Тема 5 из Блока 2 нового курса и раздел «Практика» → Тема 4.
*   **Тема 9. ИИ + Git и Подключение сторонних MCP-серверов.** Коммиты по Conventional Commits из `git diff`, автогенерация описаний Pull Request. Расширение возможностей ИИ через Model Context Protocol (MCP).
    *   *О чем:* Автоматизация работы с системами контроля версий и расширение контекста ИИ с помощью внешних серверов (баз данных, API, инструментов).
    *   *Старый курс:* **Да**, объединены Тема 6 из Блока 2 нового курса и раздел «Практика» → Тема 5.
*   **Тема 10. Отладка, рефакторинг, автотесты и документация с ИИ.** Разбор стеккрейсов и логов, поиск code smells, перевод синтаксиса. Ловушка «уверенного, но неверного» ответа. Unit-тесты с моками и edge cases, docstrings, Swagger/OpenAPI.
    *   *О чем:* Поиск багов и уязвимостей с помощью ИИ, автоматическое создание технической документации и тестов, обязательные правила валидации того, что написал ИИ.
    *   *Старый курс:* **Да**, объединены Темы 7, 8 из Блока 2 нового курса и раздел «Практика» → Тема 6.
*   **Тема 11. Безопасность ИИ-кода и данных.** Захардкоженные секреты, инъекции, «галлюцинированные» зависимости; что нельзя отправлять во внешние модели (ПДн, NDA); ответственность за результат.
    *   *О чем:* Информационная безопасность при работе с публичными LLM, риски утечки корпоративных данных, проверка сторонних библиотек, предложенных нейросетью.
    *   *Старый курс:* **Нет**, новая тема из Блока 2 нового курса.

### Блок 3. Программная интеграция LLM: API, надёжность, экономика — 2 дня

*   **Тема 12. Вызов модели из кода.** REST/SDK, роли System/User/Assistant, параметры temperature и max_tokens, стриминг, таймауты.
    *   *О чем:* Техническая интеграция ИИ в приложения: архитектура запросов через API, управление ролями в диалоге, настройка потоковой передачи ответов.
    *   *Старый курс:* **Нет**, новая тема из Блока 3 нового курса.
*   **Тема 13. Structured Outputs и Function Calling / Tool Use.** Принуждение к JSON-схеме для вставки ответа прямо в бэкенд; обеспечение вызова моделью внешней функции с корректными аргументами.
    *   *О чем:* Обучение ИИ взаимодействовать с внешним миром: как заставить модель не просто писать текст, а вызывать функции, нажимать кнопки и передавать строгие аргументы в ваш код.
    *   *Старый курс:* **Нет**, новая тема из Блока 3 нового курса.
*   **Тема 14. Отказоустойчивость ИИ-систем.** Паттерны Retry и Fallback: rate limit, недоступность API, битый JSON.
    *   *О чем:* Проектирование стабильных систем: что делать продукту, если удаленный сервер ИИ упал, выдал ошибку 429 (превышение лимитов) или сломал структуру ответа.
    *   *Старый курс:* **Нет**, новая тема из Блока 3 нового курса.
*   **Тема 15. Экономика и оценка качества (Evaluation).** Prompt/Completion tokens, расчёт стоимости запроса; минимальные evals: golden set, LLM-as-judge, контроль деградации при смене модели.
    *   *О чем:* Финансовый и качественный мониторинг. Как считать деньги за токены, как автоматически оценивать качество тысяч ответов ИИ с помощью другой модели.
    *   *Старый курс:* **Нет**, новая тема из Блока 3 нового курса.

### Блок 4. RAG — работа с корпоративными знаниями — 3 дня

*   **Тема 16. RAG vs Fine-Tuning.** Дообучение весов (дорого, долго, не гарантирует точность) против динамической подкладки контекста (дешево, быстро, гибко). Критерии выбора под бизнес-задачи.
    *   *О чем:* Архитектурный выбор: когда нужно обучать нейросеть заново, а когда достаточно подкладывать нужные документы в контекст «на лету».
    *   *Старый курс:* **Нет**, новая тема из Блока 4 нового курса.
*   **Тема 17. Эмбеддинги и векторные базы данных.** Семантический поиск по смыслу; лёгкие решения «из коробки» (ChromaDB, FAISS), поиск по косинусному сходству.
    *   *О чем:* Как ИИ ищет информацию не по ключевым словам, а по смыслу. Превращение текста в математические векторы и работа с векторными хранилищами.
    *   *Старый курс:* **Нет**, новая тема из Блока 4 нового курса.
*   **Тема 18. Chunking и сборка пайплайна.** Как нарезать документы, не теряя смысл; цепочка retrieve → augment → generate; формирование ответа со ссылкой на первоисточник.
    *   *О чем:* Инженерия данных для ИИ. Правила разделения больших текстов на куски (чанки), алгоритм их поиска и склеивания в финальный промпт для генерации точного ответа.
    *   *Старый курс:* **Нет**, новая тема из Блока 4 нового курса.
