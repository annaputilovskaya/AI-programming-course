# Cursor IDE: что это такое и как с этим жить

Если коротко: Cursor — это почти тот же Visual Studio Code, только после того, как его серьёзно «прокачали» под работу с ИИ.

Если чуть длиннее: это IDE, в которой искусственный интеллект встроен не как игрушка сбоку, а как полноценный рабочий инструмент — примерно на уровне автодополнения, только в разы мощнее.

## Что такое Cursor

Cursor — это среда разработки, построенная на базе Visual Studio Code. То есть:

- знакомый интерфейс
- те же горячие клавиши
- те же расширения (в большинстве случаев)
- та же логика работы с проектами

Но с ключевым отличием:

::: info
ИИ встроен прямо в процесс разработки — не как «отдельный чатик», а как часть рабочего процесса: редактирование кода, рефакторинг, генерация функций, анализ ошибок.
:::

## В чём главное отличие от VS Code

| VS Code                   | Cursor                                           |
| ------------------------- | ------------------------------------------------ |
| Редактор кода             | Изначально спроектирован вокруг ИИ               |
| Расширяется плагинами     | Понимает контекст проекта                        |
| ИИ — стороннее дополнение | Умеет работать с кодом на уровне файлов и логики |

Проще: VS Code + плагины = ты сам собираешь систему. Cursor = система уже собрана за тебя.

## Как используется Cursor

Cursor становится особенно полезным, когда ты используешь его не как «генератор кода», а как инструмент разработки.

### 1. Генерация кода

Написать функцию, создать API, сгенерировать шаблон.

### 2. Рефакторинг

«Упрости код», «раздели на модули», «сделай читаемее».

### 3. Анализ ошибок

«Почему это падает?», «найди баг», «предложи исправление».

### 4. Работа с архитектурой

Обсуждение структуры, генерация интерфейсов, проверка соответствия спецификации.

::: warning
Cursor — это не «пиши за меня». Это ещё один инструмент разработчика, как компилятор или дебаггер.

Безграмотное использование → получаешь хаос быстрее. Грамотное → ускоряешь разработку кратно.
:::

## Установка Cursor

### 1. Скачивание

Перейдите на официальный сайт Cursor и скачайте версию под свою ОС:

- Windows → `.exe`
- macOS → `.dmg`
- Linux → `.AppImage` или `.deb`

### 2. Установка на Windows

1. Запустите `.exe` файл
2. Подтвердите установку
3. Следуйте шагам мастера установки
4. Откройте Cursor через меню «Пуск»

### 3. Установка на macOS

1. Откройте `.dmg`
2. Перетащите Cursor в папку Applications
3. Запустите приложение
4. При необходимости подтвердите запуск в настройках безопасности

### 4. Установка на Linux

**Вариант 1: AppImage**

```bash
chmod +x cursor-*.AppImage
./cursor-*.AppImage
```

**Вариант 2: .deb (Debian/Ubuntu)**

```bash
sudo dpkg -i cursor-*.deb
sudo apt-get install -f
```

## Вход в аккаунт

После первого запуска:

1. Откройте Cursor
2. Выберите вход (Sign in)
3. Введите данные аккаунта или используйте предоставленный ключ

::: info
В рамках обучения доступ (ключ) вам выдаст менеджер.
:::

## Итог

Cursor — это:

- привычный интерфейс VS Code
- плюс встроенный ИИ
- плюс ускорение разработки

Но ключевая мысль: Cursor не делает вас разработчиком — он делает вас быстрее как разработчика. И дальше всё зависит от того, что именно вы ускоряете — продуманные решения или хаос.
